# Portfolio

Hugo single-page portfolio.

## Run locally
    hugo server
Then open http://localhost:1313

## Images
Put screenshots/gifs in `static/other/` and reference them in
`content/_index.md` as `/other/filename.png`. Needed for the current content:
serialconsole.png, physsim1.png, physsim2.png, logicsim.png

## Deploy
Push to GitHub, then Settings → Pages → Source: GitHub Actions.
